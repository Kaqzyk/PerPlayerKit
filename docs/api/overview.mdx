PerPlayerKit provides a small Java API that other Paper plugins can use to work with kit data. You access everything through a singleton `API` instance. The surface area is intentionally narrow: list the configured public kits, then apply one to any online player.

<Warning>
  The PerPlayerKit API is **not stable**. Method signatures, class names, and behavior may change in future versions without notice. Pin your integration to a specific jar version and test against new releases before upgrading.
</Warning>

## Adding the Dependency

PerPlayerKit is not published to a public Maven repository, so add the plugin jar to your project manually.

<Steps>
  <Step title="Place the jar in your project">
    Copy `PerPlayerKit-x.x.x.jar` into a `lib/` folder at the root of your project.
  </Step>

  <Step title="Declare it as a system-scoped dependency">
    ```xml pom.xml
    <dependency>
        <groupId>com.local</groupId>
        <artifactId>PerPlayerKit</artifactId>
        <version>local</version>
        <scope>system</scope>
        <systemPath>${project.basedir}/lib/PerPlayerKit-1.1.jar</systemPath>
    </dependency>
    ```

    Update the filename to match the jar you actually placed in `lib/`.
  </Step>

  <Step title="Declare the plugin dependency">
    Add `PerPlayerKit` to `depend` (or `softdepend`) in your `plugin.yml` so Paper loads it before your plugin.

    ```yaml plugin.yml
    depend:
      - PerPlayerKit
    ```
  </Step>
</Steps>

## Obtaining the API Instance

```java
import dev.noah.perplayerkit.API;

API api = API.getInstance();
```

`getInstance()` creates the singleton on first call, so it never returns `null`. What it cannot do is guarantee that PerPlayerKit itself has finished loading its kits — which is why the `plugin.yml` dependency matters. Call it from inside an event handler or command rather than from your own `onEnable()`.

## Available Methods

| Method                                 | Returns           | Description                                                                             |
| -------------------------------------- | ----------------- | --------------------------------------------------------------------------------------- |
| `API.getInstance()`                    | `API`             | The singleton API instance, created if it does not yet exist.                           |
| `api.getPublicKits()`                  | `List<PublicKit>` | A **copy** of the list of public kits configured in PerPlayerKit.                       |
| `api.loadPublicKit(Player, PublicKit)` | `void`            | Loads the given public kit for an online player, silently — no chat message or broadcast. |

## The `PublicKit` Object

| Field  | Type                  | Description                                                     |
| ------ | --------------------- | ----------------------------------------------------------------- |
| `id`   | `String`              | The kit's id — the key under `publickits` in `config.yml`.      |
| `name` | `String`              | Human-readable display name.                                    |
| `icon` | `org.bukkit.Material` | The material representing the kit in GUIs.                      |

<Note>
  `getPublicKits()` returns a copy of the internal list, so iterating or modifying the returned list never affects PerPlayerKit's own data. The `PublicKit` objects inside it are the live objects, though — treat them as read-only.
</Note>
