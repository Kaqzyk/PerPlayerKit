PerPlayerKit gives every player a focused set of commands: open the kit GUI, load any slot in a single keystroke, manage enderchest kits, share loadouts with teammates, and restock mid-fight with regear. Every command on this page is bundled under `perplayerkit.use`, so one permission node covers a normal player.

<Tip>
  Grant `perplayerkit.use` to give players everything listed here at once. Assign individual nodes only when you want to withhold something specific.
</Tip>

## Kit Menu & Quick Load

| Command       | Aliases              | Permission               | Description                                                        |
| ------------- | -------------------- | ------------------------ | -------------------------------------------------------------------- |
| `/kit`        | `/k`                 | `perplayerkit.menu`      | Open the main kit GUI to browse and manage every kit slot.         |
| `/k1` – `/k9` | `/kit1` – `/kit9`    | `perplayerkit.kit`       | Load that kit slot instantly, without opening the GUI.             |
| `/publickit`  | `/pk`, `/premadekit` | `perplayerkit.publickit` | Open the public kits menu to browse and load server-curated kits.  |

<Note>
  Servers that raise [`max-kits`](/configuration/kit-slots) above 9 also get `/k10` through `/k<max>`, registered automatically at startup. The `/kit` GUI paginates at nine kits per page.
</Note>

<Tip>
  Bind `/k1` through `/k9` to hotkeys or macros for instant kit loading mid-game.
</Tip>

## Enderchest

| Command         | Aliases                         | Permission                    | Description                                        |
| --------------- | ------------------------------- | ----------------------------- | ---------------------------------------------------- |
| `/enderchest`   | `/ec`                           | `perplayerkit.viewenderchest` | Open and view your personal enderchest inventory.  |
| `/ec1` – `/ec9` | `/enderchest1` – `/enderchest9` | `perplayerkit.enderchest`     | Load that enderchest kit slot directly.            |

Enderchest kits work exactly like normal kits, but load into the player's enderchest rather than their inventory — handy for keeping utility items one right-click away.

## Kit Management

| Command      | Aliases                      | Permission                     | Description                                                       |
| ------------ | ---------------------------- | ------------------------------ | ------------------------------------------------------------------- |
| `/copykit`   | `/copyec`, `/copyenderchest` | `perplayerkit.copykit`         | Redeem a share code into your inventory or enderchest.            |
| `/swapkit`   | —                            | `perplayerkit.swapkit`         | Swap the contents of two of your kit slots.                       |
| `/deletekit` | —                            | `perplayerkit.deletekit`       | Permanently delete the contents of a kit slot.                    |

<Warning>
  `/deletekit` removes the kit immediately with no confirmation prompt.
</Warning>

## Sharing & Transfers

| Command         | Aliases            | Permission                     | Description                                                              |
| --------------- | ------------------ | ------------------------------ | -------------------------------------------------------------------------- |
| `/sharekit`     | —                  | `perplayerkit.sharekit`        | `<slot> [player]` — send a kit to a player, or generate a share code.    |
| `/shareec`      | `/shareenderchest` | `perplayerkit.shareenderchest` | The same, for an enderchest slot.                                        |
| `/transferkits` | `/transferkit`     | `perplayerkit.transferkits`    | `<player>` — send **all** your kits and enderchests to another account.  |
| `/shareaccept`  | —                  | `perplayerkit.copykit`         | `[id]` — accept a pending share or transfer request.                     |
| `/sharedecline` | —                  | `perplayerkit.copykit`         | `[id]` — decline a pending request.                                      |

## Utilities

| Command              | Aliases | Permission            | Description                                                                        |
| -------------------- | ------- | --------------------- | ------------------------------------------------------------------------------------ |
| `/regear`            | `/rg`   | `perplayerkit.regear` | Restock whitelisted items from your loaded kit. Subject to cooldown and combat timer. |
| `/heal`              | —       | `perplayerkit.heal`   | Restore your health to full.                                                       |
| `/repair`            | —       | `perplayerkit.repair` | Repair the durability of your equipped gear.                                       |
| `/aboutperplayerkit` | —       | *(none required)*     | Show the installed plugin version.                                                 |

<Note>
  `/regear` and `/rg` are configured independently and can each run in **command mode** (instant restock) or **shulker mode** (a placeable regear shulker). See [Regear configuration](/configuration/regear).
</Note>
