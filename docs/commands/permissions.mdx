PerPlayerKit uses a node-based permission system compatible with LuckPerms and any other Bukkit permission plugin. Every command maps to an individual node, and three bundle permissions grant an entire access tier at once. Mix bundles and individual nodes to build exactly the access each group needs.

<Tip>
  [LuckPerms](https://luckperms.net) is the recommended permission plugin. Assign any node with `/lp group <group> permission set <node> true`.
</Tip>

## Permission Tiers

Tiers are **additive, not hierarchical** — `perplayerkit.admin` does not include `perplayerkit.use`. Give staff and admin groups both.

| Tier   | Permission           | Access Level                                                        |
| ------ | -------------------- | --------------------------------------------------------------------- |
| Player | `perplayerkit.use`   | All standard player-facing commands and features                    |
| Staff  | `perplayerkit.staff` | Moderator tools — inspect player kits and enderchests               |
| Admin  | `perplayerkit.admin` | Kit room, public kits, purge, data export/import, storage migration |

```bash
# A typical LuckPerms setup
/lp group default permission set perplayerkit.use true
/lp group staff   permission set perplayerkit.use true
/lp group staff   permission set perplayerkit.staff true
/lp group admin   permission set perplayerkit.use true
/lp group admin   permission set perplayerkit.staff true
/lp group admin   permission set perplayerkit.admin true
```

## Shorthand Nodes

Aliases that map to their `perplayerkit.*` counterparts. Use them if you prefer shorter node names.

| Shorthand   | Grants               |
| ----------- | -------------------- |
| `kit.admin` | `perplayerkit.admin` |
| `kit.staff` | `perplayerkit.staff` |
| `kit.use`   | `perplayerkit.use`   |

## Individual Nodes

| Permission                     | Command / Purpose                                                         |
| ------------------------------ | ------------------------------------------------------------------------- |
| `perplayerkit.menu`            | `/kit` — open the main kit GUI                                            |
| `perplayerkit.kit`             | `/k1`–`/k<max>` — quick-load kit slots                                    |
| `perplayerkit.publickit`       | `/publickit` — open the public kits menu                                  |
| `perplayerkit.viewenderchest`  | `/enderchest` — view enderchest inventory                                 |
| `perplayerkit.enderchest`      | `/ec1`–`/ec<max>` — quick-load enderchest slots                           |
| `perplayerkit.copykit`         | `/copykit`, `/shareaccept`, `/sharedecline` — redeem and answer shares    |
| `perplayerkit.sharekit`        | `/sharekit` — share a kit slot                                            |
| `perplayerkit.shareenderchest` | `/shareec` — share an enderchest slot                                     |
| `perplayerkit.transferkits`    | `/transferkits` — send all kits to another account                        |
| `perplayerkit.swapkit`         | `/swapkit` — swap two kit slots                                           |
| `perplayerkit.deletekit`       | `/deletekit` — delete a kit slot                                          |
| `perplayerkit.regear`          | `/regear`, `/rg` — restock from the loaded kit                            |
| `perplayerkit.heal`            | `/heal` — restore full health                                             |
| `perplayerkit.repair`          | `/repair` — repair equipped gear                                          |
| `perplayerkit.rekitonrespawn`  | Automatically re-apply a kit on respawn                                   |
| `perplayerkit.rekitonkill`     | Automatically re-apply a kit on kill                                      |
| `perplayerkit.staff`           | `/inspectkit`, `/inspectec` — inspect player kits                         |
| `perplayerkit.admin`           | `/kitroom`, `/savepublickit`, `/purgeitem`, `/kitdata`, `/perplayerkit`   |
| `perplayerkit.kitnotify`       | Receive kit action broadcasts (**defaults to `true`**)                    |

<Note>
  `perplayerkit.kitnotify` defaults to `true`, so every player sees kit action broadcasts unless you explicitly set it to `false` for them. To silence the messages server-wide instead, use the [message settings](/configuration/messages).
</Note>

## Recipes

<AccordionGroup>
  <Accordion title="Players can build kits but never share them" icon="lock">
    Grant `perplayerkit.use`, then deny the sharing nodes:

    ```bash
    /lp group default permission set perplayerkit.sharekit false
    /lp group default permission set perplayerkit.shareenderchest false
    /lp group default permission set perplayerkit.transferkits false
    /lp group default permission set perplayerkit.copykit false
    ```
  </Accordion>

  <Accordion title="Public kits only — no personal kit building" icon="globe">
    Skip the `perplayerkit.use` bundle and grant just the public kit node:

    ```bash
    /lp group default permission set perplayerkit.publickit true
    ```
  </Accordion>

  <Accordion title="Regear as a donor perk" icon="star">
    Deny it by default and grant it to the rank that should have it:

    ```bash
    /lp group default permission set perplayerkit.regear false
    /lp group donor   permission set perplayerkit.regear true
    ```
  </Accordion>

  <Accordion title="Silence broadcasts for one group" icon="volume-xmark">
    ```bash
    /lp group default permission set perplayerkit.kitnotify false
    ```
  </Accordion>
</AccordionGroup>
