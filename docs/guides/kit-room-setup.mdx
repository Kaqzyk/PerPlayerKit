The Kit Room is a virtual inventory of admin-curated items that players browse when building their kits. Think of it as your server's item catalogue: whatever you place inside a Kit Room page is what players are allowed to equip. Setting it up is the most important step before opening kit-based PvP to your community.

## Setting Up the Kit Room

<Steps>
  <Step title="Join the server as an admin">
    Your account needs `perplayerkit.admin` or full operator status. Without it the editor is inaccessible.
  </Step>

  <Step title="Open the Kit Room editor">
    Run `/kit` (alias `/k`) to open the main menu, then click the **Nether Star**.

    <Note>
      `/kitroom` on its own does not open the editor — it only accepts `save` and `load`. The Nether Star is the way in.
    </Note>
  </Step>

  <Step title="Fill each Kit Room page with items">
    You will see a GUI representing one Kit Room page. Place every item you want players to pick from: weapons, armor, potions, food, consumables — whatever your PvP format calls for.
  </Step>

  <Step title="Save the page">
    Hover over the **barrier block** in the corner of the GUI and **shift-right-click** it. A success sound confirms the save.
  </Step>

  <Step title="Repeat for each page">
    There are five pages. Move to the next one and repeat — fill, then shift-right-click the barrier.
  </Step>
</Steps>

<Warning>
  Leaving the GUI without shift-right-clicking the barrier discards your changes for that page. Save each page before moving on.
</Warning>

## Naming the Pages

Each page has a display name and icon shown in the selection GUI. Configure them under `kitroom.items` in `config.yml`:

```yaml config.yml
kitroom:
  items:
    1:
      name: "Crystal"
      material: "END_CRYSTAL"
    2:
      name: "Training"
      material: "WOODEN_SWORD"
    3:
      name: "Potions"
      material: "SPLASH_POTION"
    4:
      name: "Armory"
      material: "NETHERITE_SWORD"
    5:
      name: "Axe & UHC"
      material: "SHIELD"
```

`name` is the label; `material` is the icon, given as an uppercase [Bukkit Material](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Material.html) name. Restart the server after editing.

<Tip>
  Names accept [MiniMessage](/configuration/messages#minimessage-quick-reference) tags — `"<gold><b>Crystal</b></gold>"` gives you a bold gold label.
</Tip>

## Locking Kits to the Kit Room

By default players can put any legal item in a kit. Set `only-allow-kitroom-items` to make the Kit Room the single source of truth:

```yaml config.yml
anti-exploit:
  only-allow-kitroom-items: true
  import-filter: true
```

With both enabled, an item that is not in the Kit Room cannot enter a kit — including through the import button. See [Anti-exploit](/configuration/anti-exploit).

<Note>
  Removing an item from the Kit Room after players have saved kits means that item gets filtered out of their kits from then on. Announce Kit Room changes before you make them, or players will report gear "disappearing".
</Note>

## Disabling Kits Outside PvP

Kit commands can be switched off in lobby and spawn worlds:

```yaml config.yml
disabled-command-worlds:
  - "spawn"
  - "lobby"
```

The message players see lives in your [lang file](/configuration/languages) under `error.disabled-in-world`:

```yaml lang/en.yml
error:
  disabled-in-world: "<red>Kits are disabled here!</red>"
```

## Moving a Kit Room to Another Server

Once your Kit Room is dialed in, export it as a single portable file rather than rebuilding it by hand:

```bash
/kitroom save
/kitdata export kitroom myserver-kitroom
```

See [Exporting and importing kit data](/guides/kit-data).
