Two small config blocks control how the plugin looks and sounds in game: `interface` for the GUI, and `sounds` for audio feedback.

## Interface

```yaml config.yml
interface:
  glass-material: BLUE_STAINED_GLASS_PANE
  main-color: "<blue>"
```

<ResponseField name="interface.glass-material" type="string" default="BLUE_STAINED_GLASS_PANE">
  The filler item used for empty decorative slots in plugin menus. Any valid [Bukkit Material](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Material.html) name works, though stained glass panes are what the layouts are designed around.
</ResponseField>

<ResponseField name="interface.main-color" type="string" default="&#x3C;blue>">
  The plugin's accent color, written as an opening [MiniMessage](/configuration/messages) tag. Used for menu titles and highlighted text. Accepts named colors like `"<aqua>"` or hex colors like `"<color:#FF6B35>"`.
</ResponseField>

<Tip>
  Match `glass-material` to `main-color` for a coherent look. For a teal theme, pair `CYAN_STAINED_GLASS_PANE` with `"<color:#2E9E8F>"`.
</Tip>

## Sounds

PerPlayerKit plays short sounds to confirm GUI interactions and command results.

```yaml config.yml
sounds:
  enabled: true
  success: ENTITY_PLAYER_LEVELUP
  failure: ENTITY_ITEM_BREAK
  click: UI_BUTTON_CLICK
  open_gui: UI_BUTTON_CLICK
  close_gui: UI_BUTTON_CLICK
```

| Field       | Default                 | Plays when                                                        |
| ----------- | ----------------------- | ------------------------------------------------------------------ |
| `enabled`   | `true`                  | Set to `false` to disable every plugin sound globally.            |
| `success`   | `ENTITY_PLAYER_LEVELUP` | An action succeeds — saving a kit, loading a kit, a completed share. |
| `failure`   | `ENTITY_ITEM_BREAK`     | An action fails — a disabled world, a cooldown, an invalid slot.  |
| `click`     | `UI_BUTTON_CLICK`       | A button inside a GUI is clicked.                                 |
| `open_gui`  | `UI_BUTTON_CLICK`       | A GUI opens.                                                      |
| `close_gui` | `UI_BUTTON_CLICK`       | A GUI closes.                                                     |

<Note>
  Values must be valid [Bukkit Sound enum](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Sound.html) names for your server version. An unrecognized name falls back to the default sound and logs a warning to the console, so a typo never breaks a menu — check your console after changing these.
</Note>
