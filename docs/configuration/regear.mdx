The regear system lets players quickly restock consumables and key items from their currently loaded kit mid-match — no need to open inventories or visit the kit room. `/rg` and `/regear` are separate commands that you configure independently, so you can assign different behavior to each. Cooldowns and a post-damage timer keep it fair in competitive formats.

## Modes

<Columns cols={2}>
  <Card title="Command mode" icon="terminal">
    Directly restocks whitelisted items from the player's loaded kit into their inventory. Instant, no physical item involved. `command-cooldown` governs how often it can be triggered.
  </Card>

  <Card title="Shulker mode" icon="box">
    Gives the player a regear shulker box. They place it on the ground to open a special interface and click the regear shell inside to trigger the restock.
  </Card>
</Columns>

Both modes respect the cooldown and the damage timer.

## Full Configuration Block

```yaml config.yml
regear:
  rg-mode: "command"
  regear-mode: "command"
  command-cooldown: 5
  damage-timer: 5
  allow-while-using-elytra: true
  prevent-putting-items-in-regear-inventory: false
  invert-whitelist: false
  whitelist:
    - ENDER_PEARL
    - END_CRYSTAL
    - OBSIDIAN
    - GLOWSTONE
    - RESPAWN_ANCHOR
```

## Configuration Reference

<ResponseField name="rg-mode" type="string" default="command">
  Behavior of the `/rg` command. Accepted values: `"command"` or `"shulker"`.
</ResponseField>

<ResponseField name="regear-mode" type="string" default="command">
  Behavior of the `/regear` command. Accepted values: `"command"` or `"shulker"`. Configure independently from `rg-mode` to give each alias a different behavior.
</ResponseField>

<ResponseField name="command-cooldown" type="integer" default="5">
  Seconds a player must wait between successive uses of the regear command. Set to `0` to remove the cooldown entirely.
</ResponseField>

<ResponseField name="damage-timer" type="integer" default="5">
  Seconds a player must wait after taking damage before they can regear. Prevents restocking mid-exchange. Set to `0` to disable the damage restriction.
</ResponseField>

<ResponseField name="allow-while-using-elytra" type="boolean" default="true">
  Set to `false` to block regearing while a player is gliding with an elytra.
</ResponseField>

<ResponseField name="prevent-putting-items-in-regear-inventory" type="boolean" default="false">
  Shulker mode only. Set to `true` to stop players from placing items **into** the regear shulker's inventory, so it cannot be used as extra portable storage.
</ResponseField>

<ResponseField name="invert-whitelist" type="boolean" default="false">
  When `false`, `whitelist` is an allowlist — only those items are restocked. When `true`, it becomes a blocklist — every item *except* those listed is restocked. Pair `invert-whitelist: true` with an empty `whitelist` to allow everything.
</ResponseField>

<ResponseField name="whitelist" type="list of string">
  [Bukkit Material](https://hub.spigotmc.org/javadocs/bukkit/org/bukkit/Material.html) names in uppercase with underscores. Determines which items regear restocks, subject to `invert-whitelist`.
</ResponseField>

## Example Configurations

<Tabs>
  <Tab title="Same mode for both">
    The simplest setup: `/rg` and `/regear` behave identically.

    ```yaml config.yml
    regear:
      rg-mode: "command"
      regear-mode: "command"
      command-cooldown: 5
      damage-timer: 5
      allow-while-using-elytra: true
      invert-whitelist: false
      whitelist:
        - ENDER_PEARL
        - END_CRYSTAL
        - OBSIDIAN
    ```
  </Tab>

  <Tab title="A mode per command">
    `/rg` gives the quick restock for veterans while `/regear` hands out a shulker for players who prefer to pick items manually.

    ```yaml config.yml
    regear:
      rg-mode: "command"       # /rg     → instant restock
      regear-mode: "shulker"   # /regear → physical shulker box
      command-cooldown: 3
      damage-timer: 5
      allow-while-using-elytra: false
      prevent-putting-items-in-regear-inventory: true
      invert-whitelist: false
      whitelist:
        - ENDER_PEARL
        - OBSIDIAN
    ```
  </Tab>

  <Tab title="Allow every item">
    Invert the whitelist with an empty list to let players restock anything from their kit.

    ```yaml config.yml
    regear:
      rg-mode: "command"
      regear-mode: "command"
      command-cooldown: 10
      damage-timer: 5
      allow-while-using-elytra: true
      invert-whitelist: true   # empty list = nothing blocked = all items allowed
      whitelist: []
    ```
  </Tab>
</Tabs>

<Note>
  In **shulker mode**, keep `command-cooldown` low or at `0`. Placing and interacting with the shulker already paces the mechanic — a long cooldown on top of that just feels unresponsive.
</Note>

<Tip>
  Regear only restocks items that exist in the player's **currently loaded kit**. A player who has not loaded a kit this life has nothing to restock from, which is why the damage timer and `rekit-on-respawn` tend to be tuned together.
</Tip>
